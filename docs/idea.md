# Idea
I want to build a web application that is based on the popular northwind database.

## Features
- It should have authentication and user roles. 
- API calls should be authenticated.
- It should have a user interface that is modern and responsive.
- It should have a database of northwind.
- It should have a search functionality.
- It should have a pagination functionality.
- It should have a sorting functionality.
- It should have a filtering functionality.
- It should have seeding scripts that recreate the Northwind database tables from the Access database to the target database.

## Tech Stack
- Front end can be any framework of your choice - preferably React with Vite/TAilwind CSS.
- Backend - Python with fastAPI 
- Database - PostgreSQL
